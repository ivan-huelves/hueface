Hueface

Color axes for variable fonts

Load a color font, choose how each of its colors changes, and export a font with new color axes. The color variation lives in the font file itself, so it works in Illustrator, InDesign and browsers without any code. Everything runs in your browser: your font is never uploaded.

How to prepare your font

In any font editor

  • Draw each part you want to color as its own element, with a solid fill.
  • Use one exact color per role. Hueface groups parts by color, so if two parts must change independently, give them slightly different colors (for example #E6007E and #E6007F).
  • Avoid components that are rotated or scaled differently in each master. Decompose them before exporting.
  • Export a variable TrueType font with COLR color (not SVG). Static color fonts also work.

FontLab

  1. Select each element and give it a solid Fill in the Color panel.
  2. Repeat the same elements and colors in every master.
  3. File › Export Font As… › Variable TT › Customize, and turn on "OT+COLR".

Glyphs

  1. Add a Color Palettes parameter in Font Info › Masters.
  2. Add a Color layer for each palette color to every master of each glyph.
  3. Export as a variable font.

Previewing

  • Use Chrome, Edge or Firefox. Safari can't display this kind of color font yet. The exported font works in Illustrator either way.
